Status at any size — the same colour and label whether it is a row dot, a badge, a calendar chip or a card rule.
```jsx
<StatusBadge status="blocked" />
<StatusBadge status="risk" size="dot" />
<StatusBadge status="progress" size="chip">Design · Sep 12</StatusBadge>
<StatusBadge status="done" size="card"><Heading level="sub">Concept</Heading></StatusBadge>
```
- Statuses: done/ontrack, progress, risk, blocked, notstarted, build (in-house — neither bought nor pulled).
