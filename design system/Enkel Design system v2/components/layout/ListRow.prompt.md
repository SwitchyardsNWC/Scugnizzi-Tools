Touch-height list row for phones/tablets — collapse each DataTable row into one ListRow below 768px.

```jsx
<ListRow primary="Bin A-14 · Lounge chairs" secondary="On hand 12 − reserved 4" meta="8 free" onClick={open} />
```

- Stack rows directly; the row draws its own bottom hairline.
- `meta` accepts a StatusBadge for status-first lists.
